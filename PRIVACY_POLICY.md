# Privacy Policy

**Universal File Repair Tool**
**Last Updated:** February 2, 2026

## Overview

Universal File Repair Tool is an open-source file repair utility. Your privacy is important to us. This policy explains how the app handles your data.

## Data Collection

**We do not collect, store, transmit, or share any personal data.**

Specifically:

- **No analytics or tracking** — The app contains no analytics SDKs, tracking pixels, or telemetry of any kind.
- **No network requests** — All file repair processing happens entirely on your device. The app does not connect to the internet or any remote servers.
- **No user accounts** — The app does not require or support user registration or login.
- **No advertising** — The app contains no ads or ad-related SDKs.

## File Processing

- All files you select for repair are processed **locally on your device**.
- File contents are never uploaded, transmitted, or shared with any third party.
- The app reads files only when you explicitly select them for repair.
- Repaired files are saved only to locations you choose.

## Permissions

The app may request the following permissions depending on the platform:

| Permission | Purpose |
|------------|---------|
| **File/Storage Access** | To read corrupted files and save repaired files |

No other permissions are requested or required.

## Third-Party Services

The app does not use any third-party services, APIs, or SDKs that collect user data.

The app includes [JSZip](https://stuk.github.io/jszip/) (an open-source JavaScript library) for ZIP file handling. JSZip runs entirely locally and does not transmit any data.

## Children's Privacy

The app does not knowingly collect any information from anyone, including children under the age of 13.

## Changes to This Policy

Any changes to this privacy policy will be posted in this repository. Since the app does not collect data, significant changes are unlikely.
